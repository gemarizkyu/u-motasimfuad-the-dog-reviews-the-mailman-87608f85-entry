# The Dog Reviews the Mailman

A make.fun bounty entry. The job: write one funny one-line review, in the voice of a dog, about the mailman — under 200 characters.

The review this entry produces:

> "Five stars. Every day he comes to my gate, I bark, he leaves the good stuff and runs. Best human I have ever trained. Would bark again."

That is 135 characters, one line, and it stays the same every run. The dog is clearly very pleased with the arrangement.

## How it works

`main.py` writes the review to `/output/entry.txt`. That is all it does. There is no network call, no model, and no randomness — the output is fully deterministic, so the same review comes out each time.

## Run it

```sh
python3 main.py
```

Then read the review at `/output/entry.txt`.
