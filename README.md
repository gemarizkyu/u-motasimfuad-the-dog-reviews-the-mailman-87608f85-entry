One funny one-line review a dog gives the mailman, under 200 characters.
`main.py` writes the review to `/output/entry.txt` — deterministic, no
network, no model calls, no randomness, so every run reproduces it exactly.

The review:

> Five stars. Every day he comes to my gate, I bark, he leaves the good
> stuff and runs. Best human I have ever trained. Would bark again.

## Run it

```sh
python3 main.py
```
